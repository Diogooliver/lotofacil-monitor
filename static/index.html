⚠️ Importante

O índice estatístico não representa probabilidade garantida de premiação. A Lotofácil continua sendo um sorteio aleatório.

A V25.6 mede se os sinais históricos conseguem superar uma referência aleatória equivalente. Isso reduz o risco de interpretar simplesmente um núcleo maior como sendo "melhor".

🔬 Laboratório V25.6

O laboratório utiliza walk-forward:

passado → modelo → concurso futuro

O resultado do concurso avaliado não é utilizado para montar a previsão daquele teste.

🎲 Monte Carlo

Nesta versão, Monte Carlo é usado como referência estatística. O sistema simula jogos aleatórios de 15 dezenas e compara o desempenho observado com uma referência que não depende do tamanho artificial do núcleo.

🎯 Teste de tamanho do núcleo

A V25.6 não escolhe o maior núcleo pelo simples número de acertos. Cada tamanho é comparado com o baseline aleatório equivalente.

🔬 Eficácia dos sinais

Cada sinal é testado isoladamente no mesmo esquema walk-forward.

O valor principal é a diferença entre o desempenho do sinal e o baseline aleatório do mesmo tamanho.
